#  Sistema de Controle de Gastos

##  Sobre o projeto
O Sistema de Controle de Gastos é um projeto desenvolvido em Python com interface gráfica utilizando a biblioteca Tkinter. Seu objetivo é ajudar usuários a organizar e registrar despesas financeiras de maneira simples e intuitiva.

O sistema permite adicionar gastos, selecionar categorias, visualizar o total gasto, remover registros e salvar os dados automaticamente.

---

##  Funcionalidades
• Adicionar gastos  
• Selecionar categorias  
• Visualizar lista de despesas  
• Cálculo automático do total  
• Remover gastos cadastrados  
• Salvar e carregar dados automaticamente  

---

- Tkinter
- JSON
- VS Code
